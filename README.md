# Explainable Healthcare Expenditure Predictor — Demo

This Streamlit demo uses the **final 14-predictor XGBoost pipeline** from the supplied research notebook and produces:

- an annual healthcare-expenditure prediction;
- the user's complete 14-predictor input profile;
- a local SHAP waterfall aggregated back to the **original 14 predictors**;
- a ranked SHAP-contribution table;
- optional stored model-comparison and global-SHAP results.

## Important scope

The research model predicts **individual total healthcare expenditure** using the 2023 U.S. MEPS analytical sample. It is not a medical-inflation forecast, insurance premium quote, medical advice, or a model validated for Malaysia or other non-U.S. populations.

## 1. Export the trained model

Open:

`7025_Research_Project_with_Model_&_SHAPv4_demo_ready.ipynb`

Run the notebook normally. At the end, run the new **STEP 7 — EXPORT DEPLOYMENT ARTIFACT** cell.

It creates:

- `medical_expenditure_demo.pkl`
- `requirements_demo.txt`
- `model_metadata.json`

Download `medical_expenditure_demo.pkl` and place it in the same folder as `app.py`.

> Security: only load `.pkl` / joblib files that you created or trust.

## 2. Install dependencies

You can use the included `requirements.txt`, or preferably use the exact `requirements_demo.txt` generated by your Colab runtime.

```bash
pip install -r requirements.txt
```

## 3. Run the app

```bash
streamlit run app.py
```

## 4. Files

- `app.py` — Streamlit interface.
- `demo_utils.py` — prediction, SHAP aggregation and custom waterfall logic.
- `requirements.txt` — baseline dependencies.
- `7025_Research_Project_with_Model_&_SHAPv4_demo_ready.ipynb` — your notebook with an export cell appended.

## 5. Deployment

For Streamlit Community Cloud, place these files in a GitHub repository:

- `app.py`
- `demo_utils.py`
- `medical_expenditure_demo.pkl`
- `requirements.txt`

Then select `app.py` as the Streamlit entry point.

## Model inputs

The fitted pipeline uses the same 14 predictors as the research notebook:

1. age
2. BMI
3. sex
4. race / ethnicity
5. poverty status
6. insurance coverage
7. self-reported health
8. current smoking status
9. smoking frequency
10. high blood pressure diagnosis
11. diabetes diagnosis
12. cancer diagnosis
13. ADL help needed
14. BMI missingness indicator

The BMI-missingness indicator is derived automatically from the "BMI unavailable" checkbox.
